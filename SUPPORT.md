# Support

funworldmap is a small, independently maintained project. Support is best effort.

- **Playing:** open [funworldmap.com](https://funworldmap.com). The browser needs WebGL2; guessing uses a mouse or touch. Personal bests stay in that browser's local storage.
- **Bugs and data corrections:** use the [issue forms](https://github.com/GranatenUdo/funworldmap/issues/new/choose). Include reproduction steps, browser/device, and relevant screenshots. For data, include the field and authoritative source.
- **Development:** start with [Contributing](CONTRIBUTING.md) and the [documentation index](docs/index.md). Search existing issues before opening a question.
- **Security:** follow [SECURITY.md](SECURITY.md); do not post vulnerability details publicly.
- **Conduct or private project matters:** email [tobias.ens@proton.me](mailto:tobias.ens@proton.me).

Do not include credentials, private browsing data, or other personal information in public reports. There is no guaranteed response time for ordinary support requests.
