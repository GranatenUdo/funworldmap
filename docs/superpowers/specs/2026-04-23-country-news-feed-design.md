# Country News Feed on CountryPanel — Design

**Date:** 2026-04-23
**Status:** Draft — pending user review
**Sibling:** [`2026-04-22-country-pinning-guess-fixes-and-ux.md`](./2026-04-22-country-pinning-guess-fixes-and-ux.md) — the country-pinning game-rule + UX reform is shipped; news feed is the deferred "Plan 2" from the original brainstorm split.

---

## Goal

Show a "Recent news" section with up to 5 Guardian Open Platform articles from the last 7 days at the bottom of `SingleCountryPanel`, so a user clicking a country on the map immediately sees what's happening there now.

**Primary success criteria.**
- When a user selects any of the 249 countries + territories, the panel shows a labelled "Recent news (last 7 days)" section.
- Coverage-rich countries (major EU/US/UK/Asia) show 5 country-specific stories.
- Coverage-sparse countries fall back to continent-level Guardian tags (`world/africa` / `world/americas` / `world/asia` / `world/europe`) to fill the remainder; region articles are visually marked with a continent badge.
- Countries that Guardian has no tag for (e.g. some Pacific microstates) and belong to continents Guardian doesn't tag regionally (Oceania, Antarctic) show an honest "No recent Guardian stories about this country or region" line with a direct link to `theguardian.com/world/<tag>` when one exists.
- No runtime backend introduced; the pipeline is a scheduled GitHub Action that commits static JSON.

**Explicit non-goals.**
- Multi-language news (Guardian is English-only; this is a feature not a bug for a single-language product).
- Multi-source aggregation (adds editorial ranking complexity and TOS surface; the user picked Guardian-only).
- Search, filter, favourites, or saved-for-later within news.
- Analytics on news clicks — candidate for a follow-up (`news_article_opened` event).
- Using NewsAPI.org, GDELT, or any other news source (user explicitly picked Guardian).
- Freshness under 24 hours (daily GHA cadence is sufficient for "last 7 days" framing).

## Scope

### In scope

- `.github/workflows/news.yml` — new GHA, runs daily at 06:00 UTC, manual `workflow_dispatch` available.
- `scripts/news/build.ts` — TypeScript script that iterates countries, calls Guardian, writes per-country JSON.
- `scripts/news/guardian-tags.ts` — hand-curated `cca3` → Guardian tag lookup (194 entries, null where Guardian has no tag).
- `scripts/news/regions.ts` — `region` → Guardian region tag lookup (small fixed table).
- `public/news/<cca3>.json` — one static file per country, regenerated by the GHA.
- `src/components/CountryNewsSection.tsx` — new presentational component.
- `src/components/SingleCountryPanel.tsx` — one added render site + `inGameRound` gate.
- Unit tests for the sanitiser + region fallback logic.
- E2E test `e2e/country-news.spec.ts` — route-stub `/news/DEU.json`, assert rendering.

### Out of scope

- CF Worker changes (no new read-path endpoint).
- Image proxy / thumbnail rehosting (thumbnails hit Guardian's CDN directly with `referrerpolicy="no-referrer"`).
- News click telemetry (deferred; analytics Worker schema is fixed-slot and the new event would require a blob-slot extension).
- City-guessing tooltip-reveals-answer bug (separate plan).

## Architecture

### Data pipeline (build-time)

The GitHub Action runs once a day. Guardian's Open Platform developer tier enforces **1 call/sec and 5000 calls/day**. At 249 countries + territories × up to 2 calls each (country + region fallback) × 1100 ms throttle, a full run takes ≈ 9 min — well under the daily quota.

```
┌─────────────────────────────────────────────────────────────┐
│ .github/workflows/news.yml  (cron: 0 6 * * *)               │
│                                                             │
│   ┌───────────────────────────────────────────┐             │
│   │  scripts/news/build.ts                    │             │
│   │                                           │             │
│   │  for each country in countries.json:      │             │
│   │    tag = guardianTags[cca3]               │             │
│   │    if tag: fetch /search?tag=<tag>&...    │             │
│   │    if < 5 && regionTag:                   │             │
│   │      fetch /search?tag=<regionTag>&...    │             │
│   │    write public/news/<cca3>.json          │             │
│   └───────────────────────────────────────────┘             │
│                                                             │
│   commit public/news/ → triggers deploy.yml                 │
└─────────────────────────────────────────────────────────────┘
```

**Guardian API details:**
- Endpoint: `https://content.guardianapis.com/search`
- Auth: `api-key=<GUARDIAN_KEY>` (stored as GitHub Actions secret `GUARDIAN_KEY`; registered at `open-platform.theguardian.com`).
- Country tags: `world/germany`, `world/france`, etc. United States is `us-news` not `world/usa`. UK is `world/uk`. Hand-curated table covers the 249 countries + territories; countries Guardian has no tag for map to `null`.
- Region tags (hand-curated via Guardian's tag taxonomy; some regions have no clean tag):
  - `Africa` → `world/africa`
  - `Europe` → `world/europe`
  - `Asia` → `world/asia-pacific` (Guardian covers Asia + Pacific under one tag)
  - `Oceania` → `world/asia-pacific` (same tag)
  - `Americas` → `null` (Guardian has no single "Americas" tag; `us-news` + per-subregion tags exist but don't unify cleanly — accept no region fallback for this region)
  - `Antarctic` → `null` (no Guardian coverage tag)
  - Middle-East cca3s whose `region === 'Asia'` can be manually mapped to `world/middleeast` via a small subregion-override table; default is `world/asia-pacific`.
- Query parameters: `from-date=<today - 7 days>`, `order-by=newest`, `page-size=5` (country), `page-size=<5-N>*2` (region — over-fetch to allow dedupe by article id).
- Fields: `show-fields=trailText,thumbnail` — adds summary + image URL.
- Rate: ≥ 1100 ms delay between requests (Guardian's free tier is 1 call/sec). Full run ≈ 9 min.

### Output JSON shape (`public/news/<cca3>.json`)

```ts
interface CountryNewsFile {
  updatedAt: string              // ISO timestamp of GHA build
  country: { cca3: string; name: string }
  guardianTag: string | null      // e.g. 'world/germany'; null when country has no Guardian tag
                                  // — used by the client's empty-state "Browse all coverage" link
  articles: CountryNewsArticle[]  // 0..5
}

interface CountryNewsArticle {
  id: string                    // Guardian article ID, e.g. 'world/2026/apr/22/germany-coalition'
  title: string                 // plain text
  trailText: string             // plain text — HTML stripped by the build script (not on client)
  url: string                   // canonical theguardian.com URL
  publishedAt: string           // ISO timestamp
  section: string               // Guardian section ID ('world', 'us-news', ...)
  thumbnail: string | null      // optional image URL
  scope: 'country' | 'region'   // which tag produced this article
}
```

When zero articles were found for both country and region tags (or when the country has no tag and its region has no tag):

```ts
{
  updatedAt: '2026-04-23T06:00:00.000Z',
  country: { cca3: 'TUV', name: 'Tuvalu' },
  articles: [],  // empty array, not absent
}
```

### Client rendering (runtime)

`CountryNewsSection` is a new leaf component:

```tsx
interface Props {
  cca3: string
}

export function CountryNewsSection({ cca3 }: Props) {
  // fetch('/news/<cca3>.json'), render up to 5 articles, handle empty + error.
}
```

- Mounted at the bottom of `SingleCountryPanel` (below existing fields, inside the scrollable area). Placement inside the mobile expandable region so the section is visible when the panel is expanded.
- Gated on `!inGameRound` — during a country-pinning round-end panel, news is noise.
- Fetch on mount with the selected country's cca3; re-fetch when `cca3` prop changes.
- Loading state: render a subtle "Loading news…" line (no skeleton — adding skeleton chrome is scope creep).
- Error state (network fail or 404): render "News unavailable" as a single line. Panel still works.
- Empty state (`articles.length === 0`): render "No recent Guardian stories about this country or region" with a `theguardian.com/world/<tag>` link when the country's Guardian tag exists; otherwise just the copy.

**Article card layout:**
- Title (bold, medium weight)
- trailText (regular weight, smaller, max 2 lines via `line-clamp-2`)
- Metadata line: `<publishedAt>` (relative, "2 days ago") + section badge + scope badge (only when `scope === 'region'`, reads e.g. "Europe"). The relative-time formatter is a small hand-rolled helper in `src/lib/relativeTime.ts` (no new npm dep).
- Thumbnail 64×48 on the left when `thumbnail` is present; falls through to text-only when absent.
- Whole card is a single `<a href>` with `target="_blank" rel="noopener noreferrer"` — click opens the article on theguardian.com in a new tab.

### Region fallback logic (build-time)

```
country = get country by cca3
tag = guardianTags[cca3]    // string | null

countryArticles = tag
  ? await fetchGuardian({ tag, fromDate: today - 7 days, pageSize: 5 })
  : []

regionTag = regionToGuardianTag[country.region]  // 'world/europe' | null

if countryArticles.length < 5 && regionTag:
  remainder = 5 - countryArticles.length
  raw = await fetchGuardian({ tag: regionTag, fromDate: today - 7 days, pageSize: remainder * 2 })
  existingIds = new Set(countryArticles.map(a => a.id))
  regionArticles = raw.filter(a => !existingIds.has(a.id)).slice(0, remainder)
  regionArticles = regionArticles.map(a => ({ ...a, scope: 'region' }))
  countryArticles = countryArticles.map(a => ({ ...a, scope: 'country' }))
  articles = [...countryArticles, ...regionArticles]
else:
  articles = countryArticles.map(a => ({ ...a, scope: 'country' }))

writeFile(`public/news/${cca3}.json`, {
  updatedAt: new Date().toISOString(),
  country: { cca3, name: country.name.common },
  articles,
})
```

Sort order within `articles`: country-specific first (by publishedAt desc), then region-specific (by publishedAt desc). A user always sees country stories above regional ones when both exist.

## Error handling + edge cases

| Edge case | Resolution |
|---|---|
| Guardian API down during a scheduled build | GHA fails; no deploy fires; existing `public/news/*.json` stays live. Users see yesterday's data. No user-facing error. |
| Guardian rate-limits or revokes key mid-run | Script retries once per country (1 s delay), then logs and skips that country. Previous JSON stays on disk. |
| Per-country fetch throws mid-batch | Script catches + logs + keeps prior JSON file; continues with next country. Run is considered "partial success"; GHA exits 0. |
| Country's Guardian tag doesn't exist (`null` in `guardian-tags.ts`) | Skip country-specific fetch; try region fallback. If region is also null (Oceania, Antarctic), write `articles: []`. |
| Region fallback returns 0 | `articles` equals whatever country-specific articles exist (possibly 0). |
| Article has no thumbnail | Card renders without image; layout still works. |
| Article's `trailText` has unusual HTML / script tags | Build-time sanitiser strips all HTML tags; only plain text is stored. Client never receives HTML for this field. |
| User's Guardian tag page link (empty state fallback) points to a non-existent URL | We only emit the link when `guardianTags[cca3]` is non-null; tag existence is manually verified during the build of `guardian-tags.ts`. |
| 404 on `/news/<cca3>.json` (cold deploy, or file missing) | Client renders "News unavailable"; no crash. **First deploy plan: run the build script locally once during the implementation PR and commit the initial 249 JSON files alongside the code.** Merge then ships with data immediately available; the daily GHA keeps it fresh from there. |
| Article thumbnail URL returns 404 | `<img>` shows its alt text; `loading="lazy"` means no performance impact. |
| Article title or trailText is unusually long | Title uses `line-clamp-2`; trailText uses `line-clamp-2`. Fixed card heights. |

## Tests

### Unit

- `scripts/news/__tests__/sanitise.test.ts` — strip HTML tags from trailText; decode HTML entities (`&amp;`, `&#8217;`, `&#x2019;`); leave plain text untouched; handle nested tags.
- `scripts/news/__tests__/regions.test.ts` — `regionToGuardianTag` returns correct Guardian tag for each of 6 region values; Oceania + Antarctic return `null`.
- `src/components/__tests__/CountryNewsSection.test.tsx` — four tests:
  - Renders "Loading news…" while fetch is in-flight.
  - Renders 5 article links when fetch resolves with populated articles.
  - Renders region badge on articles where `scope === 'region'`.
  - Renders "No recent Guardian stories…" + tag link when `articles.length === 0` and a Guardian tag exists.
  - Renders "News unavailable" on 404.

### E2E

- `e2e/country-news.spec.ts`:
  - Route-stub `/news/DEU.json` with a fixture (5 articles, mix of country + region scope).
  - Navigate to `/#DEU`, wait for panel, assert `data-testid="country-news-section"` visible.
  - Assert 5 links to `theguardian.com/...` present.
  - Assert at least one article shows the "Europe" region badge.
  - Assert links have `target="_blank"` and `rel` containing `noopener`.

### Not tested automatically

- The Guardian API itself (the build script mocks it in unit tests).
- The GitHub Action's scheduled run (integration at deploy-time is the implicit test).
- Thumbnail image loading (browser-side `<img>` behavior; not worth an e2e assertion).

## Risks + mitigations

| Risk | Mitigation |
|---|---|
| Guardian key registered by one developer, cannot rotate without disruption | Store as GitHub Actions secret `GUARDIAN_KEY`. Document in `docs/systems/country-news.md` (created as part of this PR) how to rotate: register new key, update secret, trigger workflow. |
| Repo size grows from daily commits of `public/news/*.json` | 194 files × ~3 KB average = ~580 KB per commit. Daily commits → ~200 MB/year added to git history. Acceptable for years; if it becomes a problem, prune old commits with filter-repo. **Not a v1 concern.** |
| Guardian Open Platform TOS change | Monitor via Guardian's developer blog; if TOS narrows to paid-only, the feature disables gracefully (stale JSON remains until removed). |
| Guardian returns content in non-English edge cases (e.g. a leader's name in original script) | Accept as-is; we're aggregating what Guardian publishes, not translating. |
| `us-news` section vs `world/usa` tag confusion | Hand-curated `guardian-tags.ts` pins USA → `us-news`; unit-tested. |
| Article thumbnails slow panel render | `loading="lazy"` defers image load until scroll into view. Cards render text-first. |
| News section visible during country-pinning round-end panel clutters the educational UI | Gated on `!inGameRound`. Round-end panel shows target info only. |
| Build script takes too long (GHA job limit 6 h) | 249 countries + territories × ≥ 1100 ms throttle (Guardian's 1 call/sec free tier) ≈ 5 min baseline, + region fallback ≈ 4 min = ~9 min. Well under any limit. |
| `countries.json` changes (cca3 added/renamed) and `guardian-tags.ts` drifts | Build script logs a warning for any cca3 present in countries.json but missing from `guardian-tags.ts`. Does not fail the run — tag lookup falls through to null → region fallback. |

## Definition of done

- 194 `public/news/<cca3>.json` files exist and are fresh (generated by the new GHA on merge).
- `CountryNewsSection` renders at the bottom of `SingleCountryPanel` for every country click.
- Countries with Guardian tags show up to 5 country-specific articles.
- Countries with sparse coverage are topped up from the matching region tag; region articles wear a badge.
- Countries with neither tag show the honest "No recent Guardian stories…" line.
- GHA runs daily and commits the updated JSON.
- All unit + e2e tests green on CI.
- `docs/systems/country-news.md` documents the pipeline + how to rotate the API key.
